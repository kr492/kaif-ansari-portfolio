About Me

I graduated in Electronics and Communication Engineering, but most of what I've built lives closer to code than to circuits. Somewhere between debugging a license-plate recognition pipeline and turning a messy MySQL dataset into something query-able, I found the part of engineering I actually want to keep doing: taking raw, uncooperative data and building the systems that make it useful.

That's where I'm headed now — Data Engineering and Analytics, backed by Python, SQL, and a Databricks/AWS toolkit I've been deliberately building out. I still reach for computer vision when a problem calls for it, and I still like being the person juniors come to when hardware and software need to talk to each other.
